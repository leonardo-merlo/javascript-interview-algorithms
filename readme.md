# javascript-interview-algorithms

Coding-interview practice in JavaScript: 35 exercises grouped by pattern, each a single file with the problem statement and example calls.

> **About this repository.** Study notes in code, written while preparing for technical interviews. There is no test suite: the files print their own examples with `console.log`.

## What's inside

| Folder | Pattern | Exercises | Examples |
|---|---|---|---|
| `Arrays/` | Array traversal and in-place updates | 9 | missing positive number, move zeros keeping order, remove duplicates from a sorted array |
| `PrefixSum/` | Running sums, often with a hash map of the sums seen so far | 8 | subarray sum equals k, pivot index, subarrays divisible by k |
| `Sliding Window/` | Variable-size window over an array or string | 10 | longest substring without repeating characters, minimum window substring, minimum size subarray sum |
| `Strings/` | String scanning and stacks | 8 | balanced brackets, string compression, valid palindrome with one removal |

## Tech stack

JavaScript (ES6+) · Node.js

## Getting started

Requires Node.js. Run any exercise directly:

```bash
node "PrefixSum/subarray_sum_equals_k.js"
```
